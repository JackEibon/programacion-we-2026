# Proyecto de Desarrollo Web

## Descripción
Proyecto desarrollado como parte de la materia de **Desarrollo Web**. El objetivo principal es aplicar los conocimientos adquiridos durante el curso mediante la creación y evolución de una aplicación web.

## Objetivos

* Hacer un videojuego para vender
* Aplicar los conceptos fundamentales de desarrollo web.
* Practicar la estructura y organización de un proyecto.
* Utilizar tecnologías web para construir la aplicación.
* Mantener un registro de los cambios realizados durante el desarrollo.

## Tecnologías
El proyecto podria usar HTML o XML
